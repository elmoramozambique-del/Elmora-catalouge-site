# ELMORA catalogue — public website

The live catalogue: **https://elmoramozambique-del.github.io/Elmora-catalouge-site/**

`index.html` is **generated**, not written by hand. It is built from the private
`Elmora-catalouge` repository by `site/build.py`, which strips every internal
field before writing it. Editing it here would be overwritten on the next build.

It contains only what a client may see: titles, collections, categories,
descriptions, care text, dimensions, materials, prices and photos. No supplier
names, no SKUs, no cost notes, no internal notes, no Sales view.

Photos are served from the owner's Google Drive library.
